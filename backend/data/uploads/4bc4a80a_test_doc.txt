WYYard AI 管理平台使用手册

1. 系统概述
WYYard 是企业级 AI 综合管理平台，支持 Agent 编排、知识库管理和业务数据管理。

2. Agent 管理
Agent 是平台的核心功能单元，每个 Agent 可以配置不同的模型和系统提示词。
支持的操作：创建、启动、停止、删除 Agent。
Agent 可以通过 LangGraph 工作流进行复杂任务编排。

3. 知识库
知识库支持上传 PDF、TXT、MD 等格式的文档。
文档上传后自动分块和向量化，供 Agent 检索使用。
搜索功能基于向量相似度，返回最相关的内容片段。

4. 业务数据
业务数据通过飞书多维表格接入，支持实时同步。
可以在管理端直接查看和搜索表格记录。
支持关联多个多维表格作为数据源。

5. 系统设置
可以配置 AI 模型的 API Key 和默认参数。
飞书应用凭证也在系统设置中配置。
