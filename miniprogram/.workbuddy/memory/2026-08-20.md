## 客户列表页样式方案
- 用户要求优化客户页（`pages/customers/index`）列表样式，"看的更清晰"，先出几个方案看。
- 现状结构：搜索栏+筛选面板（到店间隔滑杆/身份/客户标签/引流人）+ 按 member_type 分组的卡片列表（行 = 昵称+首个标签 | 到店X次（Y天前）›）+ FAB。
- 清晰度问题：①分组头 24rpx 灰字锚不住；②「多少天没到店」这个最关键经营信号是括号里最小的字；③右侧信息挤；④蓝标签在一堆灰字里反而最跳。
- 产出 3 方案预览稿 `previews/customer-list-styles.html`（沿用管理端克制方向）：A 分组卡片修正（改动最小，右侧两行：天数提主+色阶）/ B 通栏表格（固定列右对齐，类飞书，扫读最强）/ C 双行信息行（meta 行+沉睡红条预警，信息最全）。
- 统一色阶规则：≤7天灰 / 8–30天蓝 / >30天红（功能性预警色 #d97070）。
- 等用户选定后落地 wxml/wxss。
- **用户已选定 C（双行信息行）**，并追加要求：详情页（`pages/customer-profile`）也调清晰，但**只出样式稿、不改代码**。
- 详情页现状结构：Hero（编辑/昵称/身份+跟进状态签/到店-消费-首次到访三统计）→ 联系方式卡 → 来源归属卡 → 背景信息卡（到访目的/创伤经历/当下卡点/其他）→ 记录区 6 tab（跟进点/沟通/活动/卡次/线下课程/交易）。
- 详情页问题：缺「最近到店」信号、空字段一排“-”噪音、6 tab 拥挤、各记录类型样式不统一。
- 产出详情页样式稿 `previews/customer-detail-styles.html`（3 帧：资料区 / 记录区·跟进点 / 记录区·活动+卡次），要点：Hero 加「N天未到店」预警签（与列表 C 同色阶）、空字段整行隐藏、基本/来源/背景三区标题化、6 tab 改分段控件带数量、所有记录条目统一解剖（日期+状态签+label-value）、卡次剩余次数提为右侧大数字。状态色全页统一：蓝=正向、灰=中性、红=预警。
- **纯样式稿，未改代码**；等用户确认后一起落地 pages/customers（C 方案）+ pages/customer-profile。
