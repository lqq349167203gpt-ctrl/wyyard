# 2026-08-08

## 修复：付费项目页成交人搜索后备注框被误填内容

**根因**：付费项目新增弹窗内容区绑了 `useEnterToNext`（按 Enter 焦点跳到下一个 input）。`CustomerSearchInput` 的搜索 input 没有拦截 Enter 键，导致用户在成交人搜索框输入名字后按 Enter，Enter 事件冒泡到 `enterToNext`，焦点跳到备注框，用户后续输入误入备注框。

**修复**：`frontend/src/components/customer-search-input.tsx` 单选/多选模式的 input onKeyDown 中拦截 Enter：
- `e.stopPropagation()` 阻止冒泡到 enterToNext
- 用户要求去掉"按 Enter 选中第一个"的行为，只保留阻止跳焦；选中成交人仅靠鼠标点击下拉项

**影响范围**：所有使用 CustomerSearchInput + useEnterToNext 的弹窗（付费项目、客户资料、邀约等页面）都受益。
