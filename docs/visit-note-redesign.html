六、行为规则

  • 每人一条：同一个人在同一栏（客户信息 / 跟进点）最多一条内容，再次保存即更新自己那条，不产生新记录
  • 权限：只能修改 / 清空自己那条；同事的只读，无编辑入口；超级管理员不受限
  • 单元格计数：显示「N人」= 已填写人数，不再用「N条」
  • 空态：任何人都没填时，单元格显示灰色「添加客户信息 / 添加跟进点」；弹窗里不显示「同事填写的」分区
  • 撤销的行（已取消邀约）：单元格禁用，不可开弹窗
  • 后端约束：visit_notes 在 (visit_id, category, created_by_id) 上加唯一约束，保存接口改为 upsert；前端打开弹窗时拉取该 visit 全部 notes 按人归并
  • 文案：分区标题固定为「我填写的」「同事填写的」；占位提示「写下你观察到的客户信息…」/「写下你观察到的跟进点…」
  • 视觉：无头像、无彩色边框、无状态标签；hairline #f0f0f0，主色 #3370ff 仅用于作者名与聚焦边框
  • 客户详情页：跟进点 tab 的邀约卡片同步改为按人平铺展示（数据源换 visit_notes），编辑入口回邀约页；涉及 backend/app/api/customer_detail.py 与 frontend/src/pages/healing-records/components/detail-view.tsx
