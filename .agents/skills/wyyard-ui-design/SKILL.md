# 无忧茶苑 UI 实现

共同授权与任务范围遵循 AGENTS.md；视觉默认值见根目录 UI-DESIGN-GUIDELINES.md。用户当前设计稿/明确选择优先，其次是指定对齐页面，再其次是默认规范。遇到默认尺寸与实际内容冲突时，自主作局部适配，说明显著偏离，不逐项询问像素。

## 执行边界

- 先检查目标组件、复用基类和相关参考页面；不为了套规范重做无关页面。
- “给方案”只做所需方案，“按方案实现”直接落地，不强制再次确认。
- 基类尽量复用；仅修改目标处必要样式。确需修改共享基类时检查直接调用方，避免全站回归。
- 保留现有业务交互、可见性、权限和用户指定的“展开/缩略”等行为；不能因范例使用 hover 就隐藏用户要求常显的按钮或归属文字。

## 实现约定

- 搜索复用 CustomerSearchInput，弹窗含搜索使用 initialFocus={false}；请求走 src/lib/api.ts。
- 表格复用 ui/table.tsx；行高、字号优先现有页面的正确实现。多行内容允许自然增高，指定顶对齐的输入框不强制居中。
- 分页优先 PaginationBar/useServerPagination，保留实际 pageSize；不要把已加载单页排序冒充全量排序。
- 异步切换保持容器和滚动稳定，避免旧请求覆盖新结果。不要为了统一空态提前 return 掉整个已加载页面。
- 表单控件约 32px 高、4px 圆角是默认值，不限制用户指定的尺寸/分段胶囊。日期筛选复用项目现有组件，按天/月/年选用正确粒度，不强制双 date 输入框。
- 操作入口必须可发现、键盘可操作；如使用悬浮显示，同步 focus-within，触控环境应可见。图标按钮提供可读名称。
- 空字段用浅灰短横线，空列表用清晰空态；加载、无权限、请求失败不可混成“暂无数据”。

## 适度自检

只检查本次修改区域：文字可读、对齐/截断正确、不横向溢出、按钮和选择态正常、空态/错误态明确。视觉变化可查看实际页面或截图；不能访问时说明未做运行时视觉核对，不伪称已验证。

代码验证按 wyyard-verify，不扫描全站并“发现即改”。只复用结构时可参考 references/patterns.md；示例不是不可更改的模板。
